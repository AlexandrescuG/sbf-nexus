## ПРОВЕРКА АДРЕСА — ОБЯЗАТЕЛЬНО ПЕРЕД ВЫПОЛНЕНИЕМ ЗАДАЧИ

Пользователь ведёт параллельно несколько чатов по разным зонам и может по ошибке прислать инструкцию не туда.

1. Если задача явно называет проект/директорию из другой зоны — **не выполнять молча**. Переспросить одной строкой: «Этот чат — Сайт и Контент, а задача про [X] — это похоже на зону [Y] ([чат]). Точно сюда?» Продолжать только после ответа.
2. Триггеры чужих зон (если это ГЛАВНАЯ тема задачи, а не побочное упоминание):
   - 🔵 CRM/Телефония: SBFCRM, CRM, Asterisk, SIP, PJSIP, диалплан, WebRTC, EspoCRM, autocall, обзвон
   - 🟢 Платформа/Боты: market_intel, SBFAcademy, Vorovka2, sbf_site, sbfconsult_site, Telegram-бот, agro_bot, News_Prod_Bot, Signals, торговые сигналы, паттерны, triple-barrier, sbf-core
3. Задачи не про код (портфельный аудит, общая координация) — не ошибка адресации, выполнять как обычно.
4. Не переспрашивать по мелочи — только когда есть реальный сигнал, что просьба нацелена на чужой проект.

Реальный продакшен-сайт: 3D-глобус (Three.js), карта сигналов (Leaflet), RU/EN. Запущен через systemd (`sbfconsult-web.service`, порт 5001) + Cloudflare Tunnel — лучший по аккуратности деплой на всём портфеле SBF. `cons-kz/` — отдельный таргетированный лендинг под Казахстан, не трогать как черновик. `_archive/` — старые итерации, не текущий код.
