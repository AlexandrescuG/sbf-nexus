# 🔴 ПОЧЕМУ ЗАПРЕТЫ ПОВТОРЕНЫ В КАЖДОЙ ГРУППЕ. По RFC 9309 бот читает
# ТОЛЬКО самую конкретную группу, где назван по имени, а группу «*»
# тогда игнорирует целиком. В прошлой версии у OAI-SearchBot, ClaudeBot,
# GPTBot и др. была своя группа с одним «Allow: /» — и черновики из
# группы «*» для них были открыты. Меняете список закрытого — меняйте
# его во всех трёх группах.
#
# ВАЖНО про Cloudflare. С 15.09.2026 он делит ИИ-трафик на категории и
# часть блокирует по умолчанию — robots.txt на это не влияет. Проверять
# в панели: AI Crawl Control / Security → Bots.

# ── Все остальные ───────────────────────────────────────────
User-agent: *
Disallow: /index-next.html
Disallow: /hero-preview/
Disallow: /_archive/
Disallow: /docs/
Disallow: /tools/
Allow: /
