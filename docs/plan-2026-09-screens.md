# sbfconsult.com — проработка экранов: план для исполнителя

Дата: 2026-09-07. Ветка `scroll-mode` (от `main` f3dae56, последний коммит 67eca9f).
Заказчик: «многое выглядит как плейсхолдеры на скорую руку — проработать все экраны отдельно, начиная с первого».

Документ — техзадание. Исполнитель идёт по экранам сверху вниз, один экран = один коммит, после каждого — проверка (§0.4). Вопросы к заказчику собраны в §12; экраны, которые от них зависят, помечены.

## 0. Рамки

### 0.1 Что уже решено и не пересматривается
- Обычная прокрутка (не поэкранная). `js/scroll-director.js` шлёт `snap-enter/leave` на секции и `sbf:section` на document.
- Знак SBF — процессор с одной ролью на экран (принимает / обрабатывает / выдаёт). Всё поведение знака — **только** в `js/logo.js` (`SBF.logo.setState(mark,{role,part,pulse})`). Секции знак не трогают, а шлют события. Знаки лежат в потоке (`.sect-mark`), общего fixed-логотипа нет и не будет. В шапке — `#nav-mark`, индикатор.
- Подпись знака стоит под кольцом: `top: calc(100% + 0.34*var(--mark-size) + 8px)`.
- Три языка (`js/i18n.js`, `_LOCALES` ru/en/ro). Любой новый текст — сразу в три локали; ключи только через `data-i18n`.
- Вендор-библиотеки только из `vendor/` (d3, topojson, three, gsap). Новых CDN не добавлять.
- Compliance: никаких обещаний доходности, никаких цитат «Reuters/Bloomberg», везде «не является инвестиционной рекомендацией», партнёры — с указанием регулятора. HTML-фолбэк без JS — нейтральный.

### 0.4 Проверка после каждого экрана
```
python3 tools/shots.py --device laptop --device laptop-low --device iphone --section <id>
python3 tools/lang-check.py --device laptop --device iphone      # RU/EN/RO, перекрытия знака
node --check <изменённые js>
```
Перед закрытием всего плана: `python3 tools/shots.py` (6 пресетов) + `lang-check.py` без `--device`. Смотреть снимки глазами, не только отчёт: `tools/shots/<device>/NN-<id>.png`. Бэкграунд-запуск: `(setsid nohup timeout 600 python3 tools/shots.py > tools/shots.log 2>&1 &)`.
Прод не меняется до `git merge` в `main` и `sudo systemctl restart sbfconsult-web.service` (делает заказчик).

### 0.5 Общие признаки «плейсхолдера», которые убираем везде
1. Текст, который подходит любой компании («индивидуальные решения для вашего будущего»). Заменяется на конкретику: что именно, когда, сколько, откуда.
2. Карточка = заголовок + одна фраза, без визуального доказательства. Каждой карточке — «улика»: число из данных, мини-график, фрагмент интерфейса, шаг процесса.
3. Пустота: экран на 70 % пуст (услуги). Либо наполняем содержанием, либо уменьшаем высоту секции.
4. Декоративный элемент без функции (тире над цифрами PRO, плавающие подписи на карте без времени/источника).
5. Отсутствие «низа»: у сайта нет футера с реквизитами, политиками и соцсетями.

## 1. Герой — `#act-map` (карта)

**Сейчас.** Карта с 3 плавающими подписями («Процентная ставка · США», «MSTR · 6 упоминаний», «Закладки новых домов · Япония») без времени, источника и смысла числа; нити почти невидимы; ядро-знак в Молдове 40px и не читается как центр; заголовок хорош; карточка «Опрос трейдера — 30 дней PRO» нормальна; бегущая строка — только календарь; строка доверия внизу — не кликабельна; лента обновляется вручную (крон не стоит).

**Цель.** Первый экран должен сам доказывать тезис «мир генерирует шум — мы распознаём закономерности»: видно, что шум настоящий (события с временем и источником), и видно, что из него уже что-то извлечено (сегодняшний заголовок брифа, ожидаемая реакция).

**Сделать.**
1. **Подписи на карте → мини-карточки события.** Разметка `.hm-label` → `.hm-event`: строка 1 — событие (title в текущем языке), строка 2 — страна · время («сегодня 15:30» / «через 2 ч» — из `calendar[].ts_utc`, локальное время посетителя), строка 3 — «обычно ±0.08 % за 30 мин по GBPUSD» из `past_reaction` (`median_atr_30m`, `symbol`, только если `n ≥ 5`). Impact — цветной маркер (low/medium/high). Не больше 4 карточек одновременно, новые вытесняют старые с фейдом. Источник — `build_feed.py` (расширить схему `hero-feed.json`: добавить `ts_utc`, `impact`, `reaction`, `symbols`; поле `generated_at`).
2. **Нити.** Контраст ×2 (сейчас `rgba(154,123,30,.8)` с быстрым затуханием — сделать затухание к хвосту не ниже 0.35), толщина у ядра 3→4 px. Вспышка ядра при приходе нити уже шлёт `sbf:thread` — шапка реагирует; ядро тоже должно (кольцо-импульс на 400 мс).
3. **Ядро.** Знак в Молдове 40→56 px с кольцом-дорожкой; подпись «SBF · Chișinău» под ним 9px mono; кольцо заполняется на 1/N с каждой пришедшей нитью и обнуляется при полном (ритм «набрали пакет — обработали»). Реализовать через `SBF.logo.setState` на `.sect-mark` героя (сейчас ядро рисуется на canvas в `hero-map.js` — заменить на DOM-знак, позиционируемый по `publishCore()`; canvas оставить только для нитей).
4. **Строка «сегодня».** Под подзаголовком: `Сегодня · 7 сентября — <brief_today.headline>` мелким шрифтом, со ссылкой «читать бриф →» на lp (UTM `utm_campaign=hero_brief`). Если `untranslated` для текущего языка — показывать английский headline, не смешивать языки (это уже ловили в ленте).
5. **Бегущая строка.** Две группы попеременно: календарь (как сейчас) и котировки из `broker_quotes.json` (`EURUSD 1.1642 ▲0.12 %`, 8–10 инструментов, цвет по знаку). Внизу строки — «обновлено N мин назад» из `updated`; старше 2 ч — котировки не показывать (нет данных лучше, чем старые данные).
6. **Строка доверия.** «Bloomberg LEI» → ссылка на LEI (уже есть на контактах); «Партнёры с лицензиями ЕС» → якорь на `#act-service-1`; «Эксперты с опытом 10–25 лет» → оставить только если заказчик подтвердит (§12.5), иначе снять.
7. **Крон.** `*/15 * * * * python3 /mnt/sbfdata/sbf-nexus/hero-preview/build_feed.py` — записать в карту юнитов (`units.txt` — источник правды по [[sbf-units-txt-is-the-source-of-truth]]), не ставить руками мимо карты.
8. **Мобайл.** Карта — фон с приглушением 0.35, карточки событий не показывать (только строка «сегодня» и одна карточка ближайшего события над CTA). LCP: `d3`+`topojson` грузить `defer` и только `≥ 768px`.

**Файлы.** `index.html` (секция `#act-map`), `js/hero-map.js`, `css/hero-map.css`, `hero-preview/build_feed.py`, `js/i18n.js` (`hero.today`, `hero.read_brief`, `hero.reaction_fmt`, `ticker.updated`).
**Готово, когда:** на карте 3–4 карточки с временем и ожидаемой реакцией, ядро с кольцом, строка «сегодня» с реальным заголовком, котировки в бегущей строке, `generated_at` не старше 15 мин после установки крона; shots/lang-check чисто.

## 3. Подход — `#act-approach`

**Сейчас.** Самый «шаблонный» текст на сайте: «Индивидуальные финансовые решения для вашего будущего» + два абзаца, подходящих любому банку. В абзаце — «криптовалют» (проверить с compliance). Линза стоит по центру ленты, что внутри неё — не объяснено, кроме подписи.

**Цель.** Одна мысль в три шага: собираем → проверяем → выдаём, и каждый шаг с числом.

**Сделать.**
1. **Копирайт.** Eyebrow «Подход». H2 «Шум снаружи — закономерность внутри». Три шага (нумерованный список `01/02/03` вертикально слева):
   - **Собираем** — «календарь, новости, котировки: N источников, обновление каждые 15 мин» (N — из `build_feed.py`/`market_intel` конфигурации, посчитать реальное число).
   - **Проверяем** — «по каждому событию — как рынок реагировал в прошлые 7 раз» (`past_reaction.n`), «паттерны — с частотой срабатывания, а не с картинкой из учебника».
   - **Выдаём** — «бриф до открытия Европы, разметка на графике, сигналы на платформе. Решение — за вами» (формулировка compliance).
   Старые абзацы удалить в трёх локалях. Ключи `approach.step1..3.title/text`.
2. **Линза с настоящим паттерном.** Лента GoldTape сейчас крутит CSV по кругу; линза фиксирована в центре. Сделать: лента едет, а при `mark:visible` останавливается так, чтобы в линзе оказалась «точка паттерна» из выбранного CSV (например `XAUUSD_triangle_breakout_may2026.csv`, свеча пробоя); в линзе — уровни, SMA20, подсветка свечи (уже есть в `_renderLens`). Под линзой — 3 чипа-легенды: «уровень», «SMA 20», «паттерн» с цветами, как в отрисовке. Hover/тач по ленте — линза едет за курсором (лента стоит), при уходе — возвращается к паттерну.
3. **Ссылка** «Как это выглядит в терминале →» на lp `chart.html?s=XAUUSD` (UTM `approach`).
4. **Мобайл.** Лента — фон 0.25 (как сейчас), линзы нет (роль — в шапке), шаги в потоке; убрать пустоту сверху (сейчас ~80px до eyebrow).

**Файлы.** `index.html` (`#act-approach`), `js/acts/act-approach.js` (режим «стоп на паттерне», hover), `css/scroll-mode.css`, `js/i18n.js` (`approach.*`).
**Готово, когда:** текст без общих фраз, три шага с числами, линза стоит на реальной свече пробоя с легендой.

## 5. PRO-оффер — `#act-platform-2`

**Цель.** Понятный оффер: что получаешь, что нужно сделать, что будет потом.

**Что закрыто за PRO на самом деле** (проверено по коду `market_intel/serve.py`, `core/journal_auth.py`, `web/index.html#anonValue`, 2026-09-07):
